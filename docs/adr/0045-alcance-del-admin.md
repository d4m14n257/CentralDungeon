# ADR-0045: Alcance del admin

## Decisión

**El admin no tiene restricciones de visibilidad, con una única excepción: la autoría de los comentarios, que tampoco puede ver**

## Por qué

Cierra **M14.4**. Necesita ver todo para moderar, y la caducidad de #44 no le aplica. La excepción del anonimato es absoluta (#43) y está por encima de este permiso: un admin puede moderar el **contenido** de un comentario sin saber quién lo escribió.
