# ADR-0085: Cambios en el OAuth de Discord

## Decisión

**Riesgo operativo asumido, con respuesta reactiva**

## Por qué

Si Discord cambia su OAuth o corta el acceso, nadie entra a CentralDungeon: no hay vía alternativa de login y no se va a construir una por si acaso. Se asume y se responde como emergencia. Queda escrito para que sea una decisión y no una sorpresa.
